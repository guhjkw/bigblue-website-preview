# Big Blue Vanuatu: website design prototype
A design prototype prepared for Big Blue Vanuatu by Pathfinder Automation Solutions: a fast, phone-friendly static rebuild of the current bigbluevanuatu.com pages, using Big Blue's own wording and photos.
It is not Big Blue's official website, which is [bigbluevanuatu.com](https://bigbluevanuatu.com); every Book button opens the live booking pages there.
